# DDR Word templates (Approach D)

Generated reports are Word (.docx) styled to match the staff-edited reference
(`DDR_CL0028_20260819.docx`, Aug 2026):

- Header: wide banner logo (`public/ddr-logo.png`) + report title only (firm name in artwork)
- Body: unified font size 20 (half-points), East Asian font PMingLiU
- Table borders: single / sz=4 / color auto; cover box cell padding 160
- Person/company DDR: **no Part 1.3** — adverse media only under screening step 2.4 (company: per-person `2.n.4`)
- Part 4.1 checklist: Item + Status only (two columns); company includes company-entity row + each natural person
- Company Part 2 step titles/methods aligned with person DDR wording (sanctions / FATF / PEP / adverse media)

## Workflow
1. Generate DOCX (company: `/api/docgen` type=DDR; person: `/api/docgen/person`)
2. Download → print → wet-ink sign Part 4 Approver Signature
3. Scan/photo → Upload signed (PDF/JPG/PNG) as document type `DDR` or `PERSON_DDR`

## Implementation
- Runtime renderer: `src/lib/docgen/ddr-docx.ts` (docx library; bilingual tables)
- Entry points: `generateDDR` / `generatePersonDDR` in `src/lib/docgen/ddr.ts` (delegate to DOCX)
- Logo fallback: `public/ddr-logo.png` then `public/logo.png`

## Part 2.4 Adverse media (manual)
- Method: Manual review (not Google CSE)
- Pass/Fail: 通過 CLEAR / 不通過 HIT / 未完成
- Completed at + Performed by + Manual notes
- Supporting files table: `KYC_ADVERSE_MEDIA` file name + uploaded at (or「沒有搜索到相關信息 / No related information found」)
- Company DDR: per screening subject under Part 2
- Person DDR: step 2.4 only

## Branding

- Footer: confidential + page numbers
- Language: bilingual ZH + EN on every user-facing line
